## Newroots AI California 

Description: NewRoots AI gives California immigrants the tools they need to thrive. It allows them to find local resources, provides links to trusted government websites, and offers summaries of useful information such as tenant rights and programs like Medi-Cal. NewRoots also includes AI-driven features that go beyond simply summarizing of information. Two of these features generate personalized roadmaps for the user; the remaining feature analyzes scam risk for text messages, emails, job offers, etc. Another useful feature of NewRoots is its Support Group feature, a forum-style, moderated space where users can ask questions and share tips.
